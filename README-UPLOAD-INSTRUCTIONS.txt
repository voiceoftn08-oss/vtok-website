# Vtok Website

## Upload to GitHub
1. Open your `vtok-website` repository.
2. Click **Add file** -> **Upload files**.
3. Upload `index.html`, `privacy-policy.html`, `terms.html`, `contact.html`, `childrens-safety.html`, and the `assets` folder (containing `vtok-icon.png`).
4. Commit the changes to the `main` branch.
5. Open Settings -> Pages.
6. Under Build and deployment, choose **Deploy from a branch**; branch `main`, folder `/(root)`, then Save.
7. Wait for GitHub Pages to publish. The expected URL is https://voiceoftn08-oss.github.io/vtok-website/

IMPORTANT: Review privacy, payment, account deletion, safety, and moderation statements to ensure they accurately match the app before submitting to Google Play. This is a starter website, not legal advice.
